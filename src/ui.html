1 · 选择设备

手机需开启 USB 调试
未检测到设备
  1. 手机「设置 → 关于手机」连点「版本号」7 次，打开开发者选项
  2. 开发者选项里开启「USB 调试」，用数据线（非纯充电线）连接电脑
  3. 手机上点「允许 USB 调试」，勾选一律允许
  4. 回到这里点「刷新」；仍无效可点下方「重启 adb 服务」
无线配对（免插线，需 Android 11 及以上）

手机端：开发者选项 → 无线调试 → 开启 → 点「使用配对码配对」，把弹出的 IP:端口 和 6 位码 填进上面 → 点配对。 配对完退回无线调试页，抄下顶部的「IP 地址和端口」填进下面一行 → 点连接。

连接地址（Android 10 及以下需先插一次线）

Android 10 及以下没有无线调试，只能：接线 → 开启无线 5555 → 读取设备 IP → 连接 → 拔线。地址会随设置保存，之后开机即可直接无线启动。
已在上方选中设备时，启动以选中设备为准，这里的地址不生效；要用无线就别选设备（或选列表里的 IP:端口 那一项）。
